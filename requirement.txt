3. login  ----------------------------------------------------------------------------------------------- 
4. refresh token  --------------------------------------------------------------------------------------- 
5. social authintication  ------------------------------------------------------------------------------- 
6. forgot password  ------------------------------------------------------------------------------------- 
7. reset password  -------------------------------------------------------------------------------------- 
8. logout  ---------------------------------------------------------------------------------------------- 
9. update profile  --------------------------------------------------------------------------------------
10. get all user (access category-admin & super-admin only access)  -------------------------------------
11. get all category-admin (access only super-admin)  ---------------------------------------------------
12. update category-admin (likes water category to gas category)  ---------------------------------------
13. delete category-admin  ------------------------------------------------------------------------------



// =================issue api==================
1. create-issue  ---------------------------------------------------------------------------------------- 
2. get all issue (category-admin & super-admin access in dashboard other wise all access in issue)  ----- 
3. single issue  ---------------------------------------------------------------------------------------- 
4. edit issue  ------------------------------------------------------------------------------------------
5. update issue (access in category-admin & super-admin)  -----------------------------------------------



// =================review api=================
1. add new review  --------------------------------------------------------------------------------------
2. reply new review  ------------------------------------------------------------------------------------
3. edit review  -----------------------------------------------------------------------------------------
4. delete review  ---------------------------------------------------------------------------------------
5. get all reviw (access in category-admin & super-admin)  ----------------------------------------------

1. user-stats  ------------------------------------------------------------------------------------------ 
2. category-admin-stats  -------------------------------------------------------------------------------- 
3. super-admin-stats  ----------------------------------------------------------------------------------- 
4. update-status (user email send to message category-admin or super-admin)  ----------------------------
5. emergency-message (user send to message category-admin)  ---------------------------------------------
